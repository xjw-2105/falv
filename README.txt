LEGAL X-RAY: ORBITAL PROMISES — DIRECTOR'S CUT
==============================================

QUICK START
-----------
1. Double-click index.html.
2. Use a current version of Chrome, Edge, or Safari.
3. Press SPACE to begin the 48-second cinematic sequence.
4. The final composition remains on screen until you reset it.

CONTROLS
--------
SPACE   Start / pause / resume / replay
R       Reset to the initial frame
M       Mute or unmute the procedural score
F       Enter or exit fullscreen
ESC     Exit fullscreen

OFFLINE OPERATION
-----------------
This folder is fully self-contained. It makes no network requests, uses no
CDN, and loads no external model, font, image, or audio file.

The background score is synthesized live in the browser after the first
SPACE press. Browsers require a user gesture before audio can begin.

PRESENTATION NOTES
------------------
- Recommended: 1920×1080 or 1440×900 at 100% browser zoom.
- The sequence automatically pauses if the browser window is hidden. Return
  to it and press SPACE to resume.
- All Aster entities are fictional and used only for illustration.
- The legal descriptions are an illustrative EU-style comparison and do not
  constitute legal advice.
